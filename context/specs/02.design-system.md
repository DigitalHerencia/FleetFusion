# Spec 02 — Preserve the Dark Neo-Brutalist Design System

**Priority:** P2  
**Depends on:** Spec 01

## Issue intent

Maintain the design system currently implemented in `app/globals.css`, `app/layout.tsx`, and the shared component library.

This is no longer a light-to-dark migration issue.

## Current design baseline

The application is dark-only.

Current font roles are:

```text
Archivo Black  → display
JetBrains Mono → body
Fira Code      → code
```

The palette derives from:

```text
background
foreground
primary
muted-primary
```

The system uses semantic aliases and derived colors rather than a multi-color candy palette.

## Geometry and controls

Preserve:

- square/minimal-radius geometry;
- hard shadows;
- compact spacing;
- visible focus;
- mechanical motion;
- semantic surface utilities;
- semantic field/action utilities.

Button-like controls use a sitewide 3px foreground border invariant.

## Shared CSS

Prefer existing shared roles before creating one-off equivalents.

Relevant families include:

```text
type-*
surface-*
control-*
navigation-*
```

## Component application

Apply the design system through the implemented presentation families:

```text
ui
blocks
templates
chart
brand
nav
shells
features
```

Do not patch individual features to compensate for a broken shared primitive or token.

Do not flatten the presentation architecture merely to centralize styling.

## Accessibility

Preserve:

- semantic controls;
- keyboard operation;
- visible focus;
- sufficient contrast;
- reduced-motion support;
- readable form text;
- touch-usable controls.

## Acceptance criteria

- [ ] The root application remains dark-only.
- [ ] The current font roles remain intact unless explicitly redesigned.
- [ ] Palette usage remains token-based and restrained.
- [ ] Button-like controls retain the 3px border invariant.
- [ ] Shared utilities remain the default styling mechanism.
- [ ] Motion remains short/mechanical and respects reduced motion.
- [ ] No feature-specific palette patchwork replaces shared design-system fixes.
- [ ] Accessibility behavior is preserved.
