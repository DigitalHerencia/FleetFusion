# Feature availability

Some FleetFusion capabilities can be controlled by organization-level feature flags as well as subscription tier and role permissions. A feature flag controls availability; it does not replace authorization checks or automatically grant a user access.

## Understand why a feature may be missing

Check these in order:

1. **Organization context:** Verify that you are viewing the correct organization.
2. **Role and permission:** Ask an administrator to confirm your membership and permission for the workflow.
3. **Subscription:** Check whether the organization’s current plan includes the capability.
4. **Organization configuration:** Ask an administrator whether the capability is enabled for the organization.

## Request a change

Describe the capability and business need to your organization administrator. Administrators should review the impact on users, plan eligibility, and operational workflow before changing configuration. Feature availability can affect multiple organization members.

Feature flags should not be changed to bypass access controls or make a restricted action available to an unauthorized user. For access guidance, see [Users and roles](/docs/admin-guides/users-and-roles); for plan details, see [Subscriptions and billing](/docs/admin-guides/billing).
