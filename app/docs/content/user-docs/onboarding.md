# Organization onboarding

Onboarding prepares the organization workspace so team members can use the operational areas with the right records and access.

## Before you begin

Have the organization’s legal or operating name, primary contact, and initial fleet and team information ready. An administrator should coordinate invitations and role assignments. FleetFusion’s membership and business records are scoped to the organization.

## Set up the workspace

1. **Confirm the organization profile.** Review the organization name and contact details in [organization settings](/docs/admin-guides/org-settings).
2. **Invite the first users.** Add teammates using their own work email addresses, then choose roles that match their responsibilities. See [users and roles](/docs/admin-guides/users-and-roles).
3. **Add core records.** Enter vehicles and drivers before relying on dispatch assignments. Use [fleet management](/docs/product-guides/fleet-management) and [driver management](/docs/product-guides/driver-management).
4. **Review required documents.** Add applicable driver and vehicle records to the compliance workflow and check dates for accuracy.
5. **Set notification preferences.** Each user can choose which supported channels to use for alerts; see [notifications](/docs/product-guides/notifications).
6. **Confirm subscription capabilities.** Check the plan and limits before enabling new workflows; see [subscriptions and billing](/docs/admin-guides/billing).

## Invite and access checks

Invitations are associated with the organization and intended recipient. Ask each person to accept their own invitation. If an invite is expired or sent to the wrong address, have an administrator review or reissue it rather than forwarding it.

Roles are not interchangeable: dispatch, compliance, IFTA, reporting, and settings access may differ. Assign the least access needed for a person’s work and review memberships when responsibilities change.

## Ready for daily use?

Use [daily operations](/docs/user-docs/daily-operations) for the first operating checklist. If something is missing, check the organization role and subscription first, then ask an administrator to resolve it.
