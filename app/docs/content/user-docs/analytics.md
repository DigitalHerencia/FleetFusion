# Analytics and reports

FleetFusion analytics brings together operational measures so authorized users can monitor trends and investigate an organization’s activity.

## Dashboard measures

The analytics area provides available KPI definitions, a dashboard snapshot, and domain metrics. Examples of business measures defined for FleetFusion include loads created per day, on-time rate, expiring documents, and IFTA reports filed. Availability and the precise measures shown can depend on configured data and the user’s access.

Use KPIs as a summary, then verify the underlying dispatch, compliance, or IFTA records before making a business decision. Metrics are only as complete as the source records.

## Work with reports

Authorized users can create, update, and remove custom reports, run a report query, and export supported reports. A good report starts with a clear question:

1. Define the business question and the time period.
2. Select relevant measures or domains.
3. Check that the scope matches the organization and the intended audience.
4. Run the report and inspect results for missing or unexpected data.
5. Save or export only the information needed for the task, and share it using approved channels.

## Common troubleshooting

| Symptom                                  | What to check                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------- |
| A metric is empty or lower than expected | Confirm the relevant source records are present and use the intended date range |
| A report cannot be opened or changed     | Check your organization role and report permissions                             |
| A result appears inconsistent            | Compare it with the underlying domain records and report filters                |
| A report option is missing               | Confirm the organization plan and enabled features with an administrator        |
