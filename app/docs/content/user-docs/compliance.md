# Compliance workflow

FleetFusion compliance workflows organize documents associated with drivers and vehicles, track expiration dates, and help a team follow up before a record becomes overdue.

## Establish reliable records

1. Identify the driver or vehicle the document belongs to.
2. Add the document with the correct type, issue details, and expiration date.
3. Check that the uploaded file is legible and belongs to the intended record.
4. Review the resulting document list and summary for missing or soon-to-expire items.

The compliance domain supports creating, updating, and deleting documents, uploading compliance files, generating expiration alerts, and bulk importing records. Access to these actions is permission-controlled.

## Review expiration alerts

Make regular checks of upcoming expirations and assign follow-up to the appropriate team member. After a renewal, update the existing record or add the replacement according to your organization’s procedure, and verify the new expiration date. Avoid treating an alert as proof that a document is valid; inspect the underlying record and file.

## Audit and bulk import guidance

- Confirm organization, driver, or vehicle association before saving a record.
- Validate dates and document types in the source data before a bulk import.
- After import, review the imported list and correct any rejected or incomplete entries.
- Keep sensitive documents available only to authorized users; use approved file-sharing procedures.

## If a document is missing

Check the selected organization and person/vehicle first, then check your role. If you are authorized but still cannot find the record, ask a compliance administrator to review it. For equipment records, see [fleet management](/docs/product-guides/fleet-management); for driver records, see [driver management](/docs/product-guides/driver-management).
